# Design taste: sources

Public sources only. Secondary sources are marked.

- https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md — the AI-default clusters, structure as information, the plan-then-critique pass, restraint, copy rules.
- https://github.com/emilkowalski/skills (`emil-design-eng`, `break-ui` and its catalog, `review-animations/STANDARDS.md`) — durations, easing, the frequency rule, the worst-case catalog, truncation rules.
- https://emilkowal.ski/ui/agents-with-taste and https://emilkowal.ski/ui/7-practical-animation-tips — `scale(.97)`, never `scale(0)`, about 65ch body.
- https://vercel.com/design/guidelines — loading timing, forms, typography, nested radii, the anti-pattern list.
- https://interfaces.rauno.me and https://rauno.me/craft/interaction-design (Rauno Freiberg) — weights ≥ 400, 16px inputs, ≤ 200ms interactions, feedback at its trigger, animation by frequency.
- https://www.refactoringui.com — chapter titles ("De-emphasize to emphasize", "Limit your choices").
- https://mohitkhare.com/blog/notes-refactoring-ui (secondary) — 25% scale steps, 45–75 characters, line-height 1.5.
- https://linear.app/now/how-we-redesigned-the-linear-ui (March 2024) and https://linear.app/now/behind-the-latest-design-refresh (March 2026) — themes from 3 variables, less chrome color, a dimmer sidebar, fewer icons, softer borders.
- https://stripe.com/blog/accessible-color-systems (2019) — perceptual lightness; 5 levels apart gives 4.5:1.
- https://docs.stripe.com/stripe-apps/patterns (empty-state, loading, communicating-state) — empty-state copy, spinner delay, toast length, state order.
- https://developer.apple.com/design/human-interface-guidelines (accessibility, typography, color, dark mode) — minimum sizes, no light weights, color never alone, 4.5:1 to 7:1.
- https://carbondesignsystem.com/components/data-table/style — row heights.
- https://ui.shadcn.com/docs/theming — token names, OKLCH pairs.
- https://www.w3.org/WAI/WCAG22/Understanding/ (1.4.3, 1.4.10, 1.4.11, 2.4.11, 2.5.8) — the thresholds.
- https://www.deque.com/axe/core-documentation/ and the axe-core rule descriptions on npm (https://www.npmjs.com/package/axe-core) — rule tags.
- https://registry.npmjs.org — the versions in tooling.md.
