
## The blueprint is written in English

The blueprint shell is English; the `BLUEPRINT` data object every stage
fills is English too — summaries, statuses, labels, decision cards,
everything — whatever language the conversation with the user runs in.
A label inherited from the placeholder stays as it is; a string you
write is written in English. One language on the page: the page is
read by whoever the workstream is shared with, not only by the person
who talked to you.
